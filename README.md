A one-page newspaper front page that sums up the world news of Sunday 22 November 2026: Iran striking US bases in Bahrain, NATO vowing to defend every inch of Polish territory, the EU–Indonesia trade deal signed in Brussels, COP31 deadlocked in overtime, Cyclone Akvan fading over Odisha, and France seeking UN action on Myanmar after the ICJ ruling.

The image is drawn at run time by `main.py` with the Python standard library only — no network, no randomness, no clock — so every run writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024 PNG, under 1 MiB).
